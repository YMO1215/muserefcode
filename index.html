FAQ

What do I get for redeeming a code?

Muse gives bonus tokens to both the person redeeming and the code owner. The exact amount is set by Meta and may change.

Where do I redeem it?

In the Muse app or on the web, open settings and look for the referral / invite code field.

Why did my code say it's used up?

Each referral code has a limited number of uses (typically 20–30). Tap "Used up / invalid" so we retire it and hand out a fresh one.

How is "uses left" estimated?

We count how many times a code has been handed out here and assume a cap of 25. It's an estimate — people outside this site may have used it too.

Will I get my own code back?

No. Codes you added from this browser are skipped when you ask for one.

Is this affiliated with Meta?

No. MuseRef is an independent community project and is not affiliated with, endorsed by, or sponsored by Meta.

Codes are public and can run out. Never pay for a referral code.
