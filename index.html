자주 묻는 질문

코드를 입력하면 무엇을 받나요?

Muse가 코드를 입력한 사람과 코드 주인 모두에게 보너스 토큰을 줍니다. 정확한 양은 Meta가 정하며 바뀔 수 있습니다.

어디에 입력하나요?

Muse 앱이나 웹에서 설정을 열고 추천·초대 코드 입력란을 찾으세요.

코드가 소진됐다고 나와요.

추천 코드마다 사용 횟수 제한이 있습니다(보통 20–30회). "소진 / 유효하지 않음"을 눌러 주시면 해당 코드를 빼고 새 코드를 나눠 드립니다.

"남은 횟수"는 어떻게 계산하나요?

이 사이트에서 코드가 나간 횟수를 세고 최대 25회로 가정해 계산합니다. 사이트 밖에서도 쓰였을 수 있어 추정치입니다.

내가 등록한 코드를 내가 받게 되나요?

아니요. 이 브라우저에서 등록한 코드는 코드를 받을 때 제외됩니다.

Meta와 관련된 사이트인가요?

아니요. MuseRef는 독립적인 커뮤니티 프로젝트이며 Meta와 제휴·보증·후원 관계가 없습니다.

코드는 공개되어 있고 소진될 수 있습니다. 추천 코드에 절대 돈을 내지 마세요.

MuseRef는 Meta와 관련 없는 독립 커뮤니티 사이트입니다. “Muse”는 해당 소유자의 상표입니다.
등록하신 코드와 익명 사용 횟수만 저장합니다. 회원가입도, 추적 쿠키도 없습니다.
